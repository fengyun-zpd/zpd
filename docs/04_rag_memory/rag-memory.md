# RAG 与记忆架构

## 检索链

查询改写 → 租户过滤 → 关键词与向量召回 → 重排 → 证据压缩 → 引用校验 → 生成 → groundedness 自检。无证据时明确拒答或转人工。

## 记忆类型

- 线程记忆：checkpoint 只用于恢复当前流程。
- 用户/订单记忆：结构化事实，带来源、时间和租户。
- 业务知识：政策文档与版本化分块。
- 图记忆：Graphiti + Neo4j 为可选增强，异步写入显式事实，不保存猜测。

## 安全

用户输入、文档和工具回包都视为不可信数据。引用必须映射到真实启用的分块；记忆读取和写入都必须带 `tenant_id`；长期记忆失败不能阻断当前工单。
