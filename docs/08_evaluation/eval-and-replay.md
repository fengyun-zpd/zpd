# 评测、回放与可观测

## 指标分层

- 领域：资格判断、退款上限、状态迁移、幂等和安全不变量。
- Agent：意图/字段准确率、必要澄清率、工具调用正确率、任务完成率。
- RAG：Recall@k、MRR、引用正确率、groundedness、租户越权数。
- 系统：P50/P95、Token、成本、回退率、人工接管率、未知操作存量。

## 数据集

黄金集覆盖正常、缺参、边界、冲突政策、提示注入、越权、超时、重复请求和未知状态。线上样本脱敏后进入候选集，人工审核后才能升级为黄金集。

## 回放

保留 prompt/model/tool/RAG/状态版本和输入哈希，不保留密钥与不必要的敏感原文。支持离线重放单节点、工具故障注入和端到端轨迹对比。Langfuse 等观测系统故障不得影响业务事务。
