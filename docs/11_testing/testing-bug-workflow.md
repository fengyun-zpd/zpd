# 测试、Bug 与迭代工作流

## 测试分层

纯函数/Schema/权限单测 → 工具与数据库集成测试 → 租户隔离、幂等、回退和 RAG 安全测试 → Playwright/SSE E2E → 黄金集评测与故障注入。

## Bug 分类

`domain`（规则或状态机）、`agent`（路由/提示/工具选择）、`rag`（召回/引用/注入）、`reliability`（超时/重试/未知状态）、`security`（越权/泄露）、`ui`（状态可见性）、`ops`（部署/观测）。每个 Bug 记录最小复现、输入哈希、期望不变量、修复模块和回归测试。

## 迭代规则

先补回归测试，再改实现；改 Prompt/模型也要锁定版本并跑同一黄金集；修复跨模块行为时同步 ADR 和事实源文档。
