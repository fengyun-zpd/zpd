# 00 产品与面试命题

## 产品命题

**OpsPilot After-Sales** 是一个面向电商售后团队的可审计多智能体工单系统。它把自然语言售后请求转成有证据、有权限、有回退路径的业务决策，而不是一个只会聊天的客服机器人。

## 一条可演示闭环

用户发起“订单少件/破损，想退款”；系统核验租户与订单，检索适用政策，给出引用证据，识别缺失材料；满足条件时生成退款草稿并触发人工审批；审批后由受控工具调用模拟售后服务；超时进入 `operation_unknown`，只能查询原操作；最终写入工单、审计和评测轨迹。

## 面试证明点

- Agent 与确定性领域服务边界清楚。
- 多 Agent 有 supervisor、子图、超时和回退，而非角色名堆砌。
- RAG 有引用正确率、租户隔离和抗提示注入测试。
- 写操作有能力矩阵、人工审批、幂等和未知状态恢复。
- 模型选择有离线黄金集、线上采样和成本/延迟对比。
- 设计可从本地 Compose 逐步演进到外部 Agent 网络。
