# 项目章程

## 目标

在 `dianshang-shouhou` 中交付一个可运行的电商售后多智能体工单系统，重点证明 Agent 应用岗位需要的工程能力：业务建模、工具契约、RAG、记忆、人工介入、可靠性、评测、可观测和可维护迭代。

## 非目标

V1 不接真实电商平台、不承诺退款资金真实流转、不做完整 CRM/WMS，不在没有评测的情况下引入复杂基础设施。

## 成功标准

- 新人可按模块目录独立修改并运行对应测试。
- 任一高风险副作用都能回答：谁批准、使用了什么证据、幂等键是什么、失败后如何恢复。
- 每次模型/提示词/检索器变化都能用同一黄金集回归。
- README 能在 3 分钟内让面试官看到闭环、证据和诚实边界。
