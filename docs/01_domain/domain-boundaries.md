# 领域边界与业务插件契约

## 平台域与业务域

平台域负责租户、身份、会话、Agent 编排、工具注册、模型、RAG、审计、评测和可靠性。业务域以插件形式提供订单、售后工单、政策、物流、退款和通知能力。StockMind 补货域仍是一个独立插件。

## 售后核心实体

`Tenant`、`Customer`、`Order`、`OrderItem`、`AfterSalesTicket`、`PolicyDocument`、`EvidenceChunk`、`Approval`、`Operation`、`AuditEvent`。

## 确定性服务

订单状态核验、售后资格、退款上限、时效计算、地址变更约束、工单状态迁移和幂等判定必须由版本化纯函数/领域服务完成。LLM 只能输出结构化意图、缺参列表和解释草稿。

## 插件接口

每个业务插件提供：实体与迁移、只读查询端口、受控写命令、政策解析器、领域错误码、黄金集和权限矩阵。插件不得直接依赖某个 Agent 框架；Agent 通过平台工具契约调用。
