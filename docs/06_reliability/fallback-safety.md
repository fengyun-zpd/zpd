# 错误处理与回退机制

## 回退阶梯

模型超时/限流 → 同端点重试（同 `operation_id`）→ 低成本只读模型 → 规则模板/离线模式 → 人工队列。任何模型不可用时都不得自动执行退款、改址或关闭工单。

## 外部副作用

执行前持久化不可变 attempt 与 `ordering`；超时、断连或响应歧义进入 `operation_unknown`，只允许用原幂等键查询和对账，禁止换键重试。需要跨服务补偿时使用 outbox + saga，补偿结果也必须审计。

## 运行控制

每个 Agent、工具和模型都有超时、预算、熔断、重试上限和 correlation id。指标至少包括回退命中率、熔断时间、工具错误率、P50/P95、人工接管率和未知状态存量。
